# Portfolio Management Module

## Purpose

Track and manage owned investment properties including rental income, maintenance, and financial performance.

## Sub-modules

### Property Management
- Property details and status
- Tenant information
- Lease terms

### Rental Management
- Rent collection tracking
- Vacancy tracking
- Rent roll reports

### Maintenance
- Work order tracking
- Vendor management
- Maintenance cost history

### Financials
- Income/expense tracking per property
- Cash flow statements
- P&L per property and portfolio

### Portfolio Analysis
- Total portfolio value
- Overall cash-on-cash return
- Portfolio diversification metrics
- Performance benchmarking
