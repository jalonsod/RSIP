# Property Investment Analysis Module

## Purpose

Perform per-property investment analysis to evaluate viability and expected returns.

## Analysis Metrics

### Core Metrics
- Purchase price
- Expected monthly rent (from Zillow estimates)
- Price per square foot
- Gross rent multiplier (GRM)
- Cap rate
- Cash-on-cash return
- Net operating income (NOI)

### Comparative Analysis
- vs. neighborhood average price/sqft
- vs. neighborhood average rent
- vs. neighborhood cap rate
- Percentile rank within ZIP code

### Investment Grade
- A: Excellent (cap rate > 8%, strong market)
- B: Good (cap rate 6-8%, stable market)
- C: Fair (cap rate 4-6%, moderate market)
- D: Poor (cap rate < 4% or weak market)
